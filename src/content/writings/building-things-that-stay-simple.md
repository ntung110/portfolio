## Start with the smallest useful thing

A useful tool usually starts with a small frustration. Something takes too long, a familiar action feels awkward, or the same question keeps coming up. The interesting part is deciding which piece of that problem is worth solving first.

## Make room for feedback

For a first version, I prefer one clear path over a dozen possibilities. A small scope makes it easier to see what works, notice what is missing, and change direction without carrying unnecessary complexity.
